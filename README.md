# 📚 Manga Reader Website

A responsive and user-friendly web application for browsing and reading manga online. Built for manga lovers, this platform provides a clean reading experience with smooth navigation and fast performance.

## 🚀 Features

- 🔍 Search and browse manga by title, genre, or popularity
- 📖 Read manga with an intuitive page viewer
- 🔄 Infinite scroll for chapter images

## 🛠️ Tech Stack

- **Frontend:** React.js 
- **Backend:** JavaScript
- **Styling:** CSS/ React
- **Deployment:** Vercel
